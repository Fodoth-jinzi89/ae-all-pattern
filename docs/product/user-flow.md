# 玩家操作流程

## 绑定

1. 放置全样板链接器，并让它接入有效 AE 网络。
2. 手持绑定器普通右击链接器。
3. 绑定器记录链接器的维度、坐标、所有者与绑定结构版本；提示“已选择 AE 链接器”。
4. 玩家靠近目标机器，潜行右击机器；绑定成功后链接器选择仍保留，可继续绑定下一台机器。
5. 服务端依次检查：绑定器状态、距离、权限、区块已加载、链接器仍属于可用 Grid、目标存在可用适配器。
6. 服务端创建绑定记录并扫描配方，客户端显示贴合机器的紫色立体框架。
7. AE2 合成目录刷新，终端出现新的可合成输出。

## 合成

1. 玩家在 AE 终端请求一个由虚拟样板提供的输出。
2. AE2 选择链接器提供的 `IPatternDetails`。
3. `ICraftingProvider.pushPattern` 收到 AE 已预留的输入。
4. 链接器先把完整输入接管到自己的持久 `IncomingBuffer`；全部接管成功后才接受任务。
5. MVP 单输入适配器先模拟绑定面；该面不能完整接收时，按确定性顺序寻找机器真正可接收该物品的输入能力。机器堵塞时输入继续留在缓冲。
6. 多输入机器只有在适配器提供预留/回滚或独占转运保证时开放，不能假装多个独立槽写入是原子操作。
7. 链接器持续抽取绑定机器通过输出能力公开的所有物品，并注回该链接器所在的 AE 网络；来源可以是当前订单、旧库存或其他物流。
8. AE2 观察到预期结果进入网络，合成任务继续或完成。

ME 网络容量不足时，链接器不从机器抽取；容量在模拟后发生竞争时，已抽取但未注入的余量进入链接器的持久回收缓冲，随后重试。

## 解绑与失效

- 对已绑定机器再次潜行右击：请求解绑，服务端确认后删除记录，但保留当前链接器选择。
- 链接器被拆除：绑定进入离线状态，不再公开样板；记录可按配置保留一段时间或立即清理。
- 机器被替换：方块实体类型指纹不匹配，绑定失效，不把材料投入新方块。
- 网络拆分或合并：链接器从自己的 Grid Node 重新解析当前网络并请求 AE2 刷新。
- 区块未加载：显示离线，不主动强加载。

## 反馈

- 绿色提示：绑定成功、配方数量、使用的适配器。
- 黄色提示：机器可识别但部分配方被安全策略过滤。
- 红色提示：无权限、距离过远、未加载、无适配器或目标已变化。
- 调试模式：显示绑定 ID、适配器 ID、目录代数、缓存命中和最近失败原因。
