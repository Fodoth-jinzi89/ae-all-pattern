# 当前支持矩阵

本页描述仓库当前代码，而不是最终愿景。具体依赖版本以根目录 `gradle.properties` 为唯一构建事实来源。

| 能力 | 状态 | 说明 |
| --- | --- | --- |
| Minecraft 1.21.1 + NeoForge 开发骨架 | 已实现 | 完整构建和单元测试可运行 |
| AE2 依赖与公开 API 路线 | 已配置 | 尚未注册 Grid Node/provider |
| 全样板绑定器物品 | 占位 | 已注册，无交互行为 |
| 两阶段绑定 | 计划中 | Phase 1 |
| 紫色 AE 包围框 | 计划中 | Phase 1 |
| 虚拟处理样板 | 计划中 | Phase 2 |
| 原版熔炉 | 计划中 | Phase 2 |
| Mekanism 电炉/工厂 | 计划中 | Phase 3 |
| JEI 展示 | 计划中 | Phase 4，始终不是服务端真源 |
| 概率/流体/化学品/跨维度 | 暂不支持 | 需专用适配与安全模型 |

任何 Release 都必须同步更新本表，避免“文档愿景”被误认为已发布功能。
