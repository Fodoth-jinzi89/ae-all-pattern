# 客户端、服务端与紫色包围框

## 分层

服务端负责绑定、权限、RecipeManager、AE Grid、机器事务和持久化。客户端只负责：

- 渲染已授权同步的绑定；
- 显示绑定器提示与诊断 HUD；
- 可选 JEI 展示。

客户端类放在 `client` 或 `compat.jei`，通过 client-only mod 入口注册。服务端公共类不能 import 渲染、JEI 或客户端事件。

## 包围框实现

“紫色 AE 风格实体框”实现为世界渲染阶段的线框/半透明外壳，不创建真实实体：

- 使用目标方块的渲染/碰撞包围盒；多方块可由适配器提供整体 AABB。
- 颜色以 AE 紫为主，选中时有轻微脉冲但不遮挡纹理。
- 只渲染玩家有权查看且在配置距离内的绑定。
- 客户端保存服务端同步的坐标集合，不每帧扫描世界方块实体。
- 区块卸载、解绑、维度切换时立即移除缓存。
- 深度测试、透明排序和相机插值需要在不同光影/渲染模组下人工验证。

## 网络同步

S2C 包只含渲染所需数据：binding UUID、维度、位置/AABB、状态、短错误码。配方全集和所有者敏感信息不应广播给无关玩家。客户端永远不能通过 C2S 包直接写入绑定；它只能提出带交互上下文的请求。
