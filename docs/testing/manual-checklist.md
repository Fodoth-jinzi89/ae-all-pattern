# 人工验收清单

## 启动

- [ ] 无 JEI 的专用服务器可启动。
- [ ] 无 Mekanism 时客户端与专服可启动。
- [ ] 安装 AE2 + JEI + Mekanism 后无缺失依赖或错误版本提示。

## 绑定

- [ ] 普通右击链接器后绑定器显示已选锚点。
- [ ] 潜行右击熔炉/电炉后服务端创建绑定。
- [ ] 距离过远、无权限、区块未加载时拒绝且不改数据。
- [ ] 重启后绑定恢复。
- [ ] 机器被替换后绑定安全失效。
- [ ] 解绑后 AE 目录和紫色框同时消失。

## 样板与合成

- [ ] 所有允许的 smelting 具体输入都出现为可合成输出。
- [ ] 完全相同的虚拟样板不重复。
- [ ] `/reload` 与 KubeJS 重载后增删配方正确。
- [ ] 投料模拟失败时不消耗任何材料。
- [ ] 输出堵塞时不吞物、不错误完成 AE 任务。
- [ ] 多个相同链接器优先级和并行行为可预测。

## 客户端

- [ ] 紫色框贴合目标，移动相机无明显闪烁。
- [ ] 维度切换/区块卸载后不残留框。
- [ ] 无权限玩家看不到敏感绑定信息。
- [ ] 光影和常见渲染模组下仍可辨认。

## 性能

- [ ] 空闲时不扫描配方。
- [ ] 1000+ 配方目录重建耗时有记录且无持续 TPS 下降。
- [ ] 玩家加入不触发全量重建。
- [ ] `/reload` 只刷新一次，并且只通知受影响 provider。
