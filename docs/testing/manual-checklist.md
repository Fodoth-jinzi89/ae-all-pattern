# 人工验收清单

## 启动

- [x] 无 JEI 的专用服务器可启动。
- [x] 无 Mekanism 时客户端与专服可启动。
- [x] 安装 AE2 + JEI + Mekanism + Applied Mekanistics 后客户端、专服与 GameTest 无缺失依赖或错误版本提示。

## 绑定

- [ ] 普通右击链接器后绑定器显示已选锚点。
- [ ] 潜行右击熔炉/电炉后服务端创建绑定。
- [ ] 首次绑定后无需重新选择链接器，可连续潜行右击绑定第二、第三台机器。
- [ ] 距离过远、无权限、区块未加载时拒绝且不改数据。
- [ ] 重启后绑定恢复。
- [ ] 机器被替换后绑定安全失效。
- [ ] 解绑后 AE 目录和紫色框同时消失。

## 样板与合成

- [x] 聚合样板中的流体输出能作为 AE 可合成键发布。
- [ ] 回旋式气液转换机生成的聚合样板保留真实流体和 Chemical 输入/输出及数量。
- [ ] 所有允许的 smelting 具体输入都出现为可合成输出。
- [ ] 完全相同的虚拟样板不重复。
- [ ] `/reload` 与 KubeJS 重载后增删配方正确。
- [ ] 投料模拟失败时不消耗任何材料。
- [ ] 输出堵塞时不吞物、不错误完成 AE 任务。
- [ ] 多个相同链接器优先级和并行行为可预测。

## 客户端

- [ ] 紫色立体框架贴合目标，具有暗色外壳与发光紫色内芯，移动相机无明显闪烁。
- [ ] 维度切换/区块卸载后不残留框。
- [ ] 无权限玩家看不到敏感绑定信息。
- [ ] 光影和常见渲染模组下仍可辨认。

## 性能

- [x] 空闲时不扫描配方。
- [x] 10000 指纹规模门禁通过，目录重建耗时由 `/aeallpattern perf` 记录。
- [x] 玩家加入只同步所有者绑定框，不触发配方目录重建。
- [ ] `/reload` 只刷新一次，并且只通知受影响 provider。
